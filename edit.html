Publier sur GitHub

Pour publier, cet appareil a besoin d’un jeton GitHub limité au dépôt msk-tcg. Il est enregistré uniquement sur cet appareil, jamais dans le code.

  1. Ouvrir github.com → nouveau jeton (fine-grained)
  2. Repository access : Only select repositories → msk-tcg
  3. Permissions → Contents : Read and write
